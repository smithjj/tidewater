# Asset sources

The source models the game's runtime copies come from. They live here so the exact bytes that produced a
shipped model stay recoverable from a clone; the game itself loads from `public/models/`, never this folder.

| Model | The game loads | Notes |
|---|---|---|
| `lobster_trap_decimated.glb` | `public/models/props/lobster_trap_decimated.glb` | The trap alone, 85,616 triangles (from 1,066,100 in `lobster_trap.glb`). One scene (`LOBSTER TRAP \| Decimated`). The game takes the pot from it by material family: WOOD/TWINE/CORD/IRON. An earlier export also carried the full buoy as a second scene (231,100 triangles in all); the game never used that part, so the runtime copy is this file. |
| `lobster_trap.glb` | — | The full-detail original (1,066,100 tris). No longer loaded — kept as the source. |
| `lobster_trap_buoy.glb` | `public/models/props/lobster_trap_buoy.glb` | The marker float: 92,180 triangles (FLOAT, STEM, WEAR, METAL, PAINT — a trimmed copy of the 145,484-triangle original, without its rope loop, knots and peg). The game paints the FLOAT material red with a yellow band, since the export has no colour for it. Byte-identical to the runtime copy. |
| `pelagic_30.glb` | `public/models/boats/pelagic_30.glb` | Byte-identical to the runtime copy. |
| `mini_fishing_boat.glb` | `public/models/boats/mini_fishing_boat.glb` | The one-man mini fishing boat, 129,192 triangles, one embedded image, three scene roots: the boat (`MINI BOAT \| Move whole assembly`, 399 parts, length along X, bow on -X, ~3.3 m), a studio ground shadow and the reference photograph. `src/world/boats/MiniFishingBoat.js` loads only the boat and leaves out the text decals (three meshes, 60,000 triangles). The file has no colour for the hull's camouflage and no texture coordinates on the seats, so the game paints the hull marsh green and the seats reed green by material. Byte-identical to the runtime copy. |
| `eagle-ray.glb` | — | The spotted eagle ray study, 130,322 triangles: a sculpted disc and duckbill (69,408), a five-metre whip, fins, and fine anatomy (gills, spiracles, mouth, pores, barbs). Not loaded at run time: `tools/creatures/bake-eagle-ray.mjs` decimates the disc, the whip and the fins into two levels of detail in the fish frame and writes `src/world/fish/EagleRayData.js`, which the fish schools draw close up. Re-run it after a re-export. The "irregular ivory spots" material is procedural in the file and exported without a colour, so the game's own ring pattern colours the back. |

The copies the game loads are kept in step by hand, so a re-export means copying the file into
`public/models/` as well. If they ever differ, the game is using the `public/` one.

## Blender sources (`source/`)

What the two models of the newest stretch were built from, so a re-export does not need the original machine. Copied as they were
(the build scripts are unchanged); the scratch folders, `__pycache__`, the preview renders and the previous-session backups were left out.

| Folder | Contents |
|---|---|
| `source/mini-fishing-boat/` | `mini_fishing_boat.blend` (the finished scene), `build_mini_fishing_boat.py` then `finish_mini_fishing_boat.py` (run in a connected Blender session, in that order; they find their files next to themselves), and `validation.json` (the mesh checks of the export). **The reference image is not in the repository** (it is someone else's, see Provenance) and has been removed from the `.blend` too (its hidden reference object and the packed image); `build_mini_fishing_boat.py` loads `hidden-marsh-transp-background.webp` from its own folder, so a rebuild from scratch needs your own copy of that file there (the seat's reed texture is generated by the script, so it is still in the `.blend`). Export the boat root (`MINI BOAT \| Move whole assembly`) as `mini_fishing_boat.glb` and copy it to `assets/` and `public/models/boats/`. |
| `source/eagle-ray/` | `spotted_eagle_ray.blend` (the finished scene, with the swim animation), the scripts in the order `build_eagle_ray.py`, `finish_eagle_ray.py`, `refine_and_render.py`, `polish_anatomy.py`, `animate_eagle_ray.py` (`render_eagle_ray.py` and `render_swim_gif_frames.py` make the previews), `asset_validation.json` and the original `README.md` (the model's notes: anatomy, rig, controls). **The reference photograph is not in the repository** (it is someone else's, see Provenance), and it has been removed from the `.blend` too (its hidden reference object and the packed image); `build_eagle_ray.py` loads `Pacific-Spotted-Eagle-Ray-009.jpg` from `ROOT`, so a rebuild from scratch needs your own copy of that file there. **These scripts have the author's folder hard-coded** (`ROOT = r'C:\Users\smith\...\codex-projects\assets\eagle-ray'`): change `ROOT` to this folder before running them. After a re-export, copy `eagle-ray.glb` to `assets/` and run `tools/creatures/bake-eagle-ray.mjs` (see above). |

Neither `.blend` carries its reference image any more (removed, not just left unpacked); the mini boat's seat texture is generated by its script and stays.
